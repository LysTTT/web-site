# Золотистый Петушок

Статический сайт с калькулятором оптовых заказов.

## Запуск

Требуется Python 3. Запустите локальный сервер:

```powershell
python main.py
```

Откройте <http://127.0.0.1:8000/index1.html>.

## Структура

- `index1.html` — разметка страницы.
- `static/css/styles.css` — стили.
- `static/js/price-calculator.js` — калькулятор цены.
- `static/images/` — изображения страницы.
- `main.py` — локальный сервер статических файлов.

Сейчас сервер только отдаёт сайт: API и логики предметной области на backend в проекте нет.
